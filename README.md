\# PoC 4 – Avalonia MVVM



Dieser PoC testet eine modulare Avalonia-Anwendung mit MVVM, Dependency Injection und Navigation.



\## Test



Im Ordner dieser README ein Terminal öffnen:



```powershell

dotnet run --project AvaloniaMVVM/AvaloniaMVVM.csproj

```



In der Anwendung:



1\. Eine neue Source erstellen und speichern.

2\. Für die Source einen Request erstellen und speichern.

3\. Zwischen Requests, Tabs, Dashboard, Settings und About wechseln.



\## Erwartetes Ergebnis



Sources und Requests lassen sich bearbeiten und die Ansichten reagieren auf Navigation und Zustandsänderungen.
